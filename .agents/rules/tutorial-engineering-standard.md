# 通用技术教程编写工程规范 (Universal Technical Tutorial Engineering Guide)

本规范定义了一套**跨语言、高可用、可标准化复用**的技术教程架构体系与设计准则。适用于任何后端或系统级技术栈（如 Go、Python、Node.js、Rust、Java 等）的体系化教程开发。

---

## 🎯 教程核心战略定位：三大核心支柱

任何一套具备工业级水准的技术教程，必须同时立足于以下三大核心支柱：

```text
                     ┌──────────────────────────────┐
                     │   现代工业级教程三大战略支柱   │
                     └──────────────┬───────────────┘
                                    │
         ┌──────────────────────────┼──────────────────────────┐
         ▼                          ▼                          ▼
  【 1. 广度全面 】          【 2. 极速入门 】          【 3. 大厂就职 】
日常工作底座全覆盖          认知负荷极低开箱即跑        直击常考 80% 核心考点
涵盖工程全生命周期          50~80行自洽代码即学即见    结构化满分回答模板直接背
```

### 支柱一：广度全面 (Full Spectrum of Engineering Practice)
- **目标定位**：覆盖工程师在企业实际工作中所需的**完整日常开发切面**，拒绝只讲语法糖或个别孤立框架；
- **通用的九大工程知识维度**（各技术栈按需映射）：
  1. **现代工程工具链**：现代运行时/编译器特性、工程依赖拓扑与包管理机制、代码规范与格式化门禁、原生测试套件、多环境配置安全治理；
  2. **核心类型与底层内存模型**：栈/堆内存物理模型、值传递与引用传递、内存共享副作用与深拷贝隔离、静态类型收窄与守卫、工具类型派生、类型变宽消除；
  3. **异步基石与并发控制流**：底层任务调度引擎、异步异常链式治理、并发聚合与局部容灾降级、全链路执行上下文追踪、未捕获异常防御与进程优雅停机；
  4. **文件、二进制与流式传输**：异步非阻塞 I/O 操作、文件系统原子写入防半写损坏、二进制底层连续内存模型与切片陷阱、流式管道与背压（Backpressure）流量控制、跨平台标准流互通；
  5. **网络编程与实时通信**：原生轻量服务与路由分发、传输层套接字通信、面向字节流特征与应用层消息定界解粘包、长连接协议升级握手与心跳保活重连；
  6. **并发模型与多核算力利用**：子进程流式调用与命令注入防御、多核进程集群端口复用与故障自愈、工作线程/协程并行计算与密集运算防主调度阻塞；
  7. **数据治理与安全防御**：运行时不可信数据强模式校验、嵌入式持久化操作与参数化预编译防 SQL 注入、Web 安全防御属性与轻量无状态令牌签发验证；
  8. **现代框架底层设计哲学**：高性能框架的作用域封装与隔离机制、企业级框架依赖注入（IoC/DI）解耦思想与面向切面编程（AOP 拦截器）；
  9. **前沿标准协议与综合编排**：行业通用标准化工具交互协议、流式数据打字机推送与客户端级联中断、多技术融合的高并发流式治理收官引擎。

### 支柱二：极速入门 (Zero-Friction Fast Onboarding)
- **降低认知负荷（Cognitive Load）**：
  - 拒绝生僻晦涩的学术黑话与冗长铺垫；
  - 彻底杜绝低幼化生活比喻，坚持**严谨、硬核、纯粹的工程师架构语言**；
  - 全篇贯穿统一的**工程三段式结构**：
    - **是什么？（定义契约）**：用最准确的技术语言给出底层机制定义；
    - **为什么需要它？（痛点与事故防御）**：直接指出如果不使用该机制，生产环境会发生什么故障（如：内存 OOM、数据污染、死锁雪崩）；
    - **生产怎么用？（工程最佳实践）**：交代企业级生产落地的标准模式。
- **50~80 行代码黄金法则**：
  - 每个专题的验证代码严格收敛在 **50~80 行**；
  - 杜绝为了设计模式而写的深层抽象或无意义辅助类；
  - 纯函数与轻量类驱动，读者 1 分钟即可通读并洞察核心执行流。
- **环境自闭环与零摩擦执行**：
  - 动态分配网络端口，杜绝端口冲突；
  - 临时创建的测试资源在结束时自动清理，保持工作区零残留；
  - 涉及网络、定时器或并发任务时，必须受控平稳退出（`exitCode: 0`），保障支持全自动串行验证。

---

### 支柱三：大厂面试就职 (Interview-Ready & High-Score Mastery)
- **聚焦 80% 真实常考黄金高频题**：
  - 每个专题不设机械数量限制，按需全量收录大厂历年真题中真正高频出现的核心硬核考点；
  - 专挑考察“底层机制、系统设计、故障排查（Troubleshooting）与技术选型权衡”的高含金量题目。
- **结构化“满分答题模板”**：
  1. **🎯 面试官考点**：点破题目背后的考察维度（如：考察内存分区、考察并发竞态条件）；
  2. **💡 满分回答模板**：
     - **分点陈述（1, 2, 3）**：逻辑严谨，核心技术关键词**加粗**；
     - **横向对比表格**：针对容易混淆的概念，必须使用多维度对比表格；
     - **核心落地代码**：给出可在面试白板上手写的精炼代码片段或防御配置。
  - **合上电脑即可背诵**：答案高度结构化，读者在面试前通读即可形成清晰的应答逻辑与肌肉记忆。

## 📐 目录与交付物分层体系

仓库按照“阶段总览”到“原子专题”严格实行分层交付：

```text
📁 0x-阶段目录名称/
├── 📄 README.md              -> 阶段总览：核心工程心智 + 底层机制图谱 + 阶段专题导航表格 + 统一运行指令
└── 📁 xx-原子专题子目录/
    ├── 📄 README.md          -> 认知输入：工程三段式 + 15行核心切片 + 控制台输出快照
    ├── 📄 main.<ext>         -> 动手实证：50~80 行自洽纯粹代码 (零冗余、自闭环)
    └── 📄 QA.md              -> 记忆固化：大厂真实高频核心真题 + 结构化满分答题模板
```

### 交付物铁律：
1. **阶段总览覆盖律**：每个阶段根目录必须配备 `README.md`，承上启下串联本阶段全量专题；
2. **专题三位一体律 (Triad Rule)**：每个原子专题目录内部**必须且仅允许**包含 `README.md`、`main.<ext>`、`QA.md` 三大核心交付物；
3. **单一职责原则**：一个专题只讲透一个原子级核心原语，杜绝多技术杂糅；
4. **独立可验证性**：每个专题的代码必须能独立执行并产生确定性的自验输出，不得强依赖其他专题的执行状态。

## 🛠️ 工程化基建三件套

任何技术栈教程仓库根目录必须配备统一的工程化基建：

1. **统一自动化构建脚本（如 `Makefile`）**：
   - 包含语法/类型检查、代码风格规范、单元测试套件、以及全阶段一键顺序运行目标；
2. **演进进度看板（如 `PROGRESS.md`）**：
   - 列出全部阶段与专题的完成打勾项（`- [x]`），直观呈现技术全貌与交付状态；
3. **技术全景学习指南（如 `learning-guide.md`）**：
   - 提供知识递进路线图与科学刷题推演指南。

### 模版 4: 阶段化 Git Commit 提交标准与语义规范

为了保证跨语言教程仓库在代码审计、版本演进与读者追溯过程中的最高工程美感，强制遵守阶段化递进提交范式：

#### 1. 提交前缀与语义规范
- **基建初始化**：
  `chore: 初始化 <技术栈> 现代工程实战教程工程架构与基建`
  - 范围：根目录配置文件（`pyproject.toml` / `package.json` / `go.mod`）、依赖锁定文件、`Makefile`、`.gitignore`、单测脚手架及 `.agents/rules`。
- **阶段化递进交付**：
  `feat(阶段零): 交付<阶段零主题>与<核心能力>`  
  `feat(阶段一): 交付<阶段一主题>与<核心能力>`  
  ...  
  `feat(阶段N): 交付<阶段N主题>与<核心能力>`
  - 范围：必须同时包含该阶段的一级 `README.md`、全部子专题源码、专题 `README.md` 与 `QA.md`。
  - 准入要求：每个阶段提交必须保证代码独立可编译、单测 100% 通过、静态检查零报错。
- **文档与看板收官**：
  `docs: 完善全景成长路径与全量专题建设进度看板`
  - 范围：根目录 `README.md`、`learning-guide.md`、`PROGRESS.md` 等全景导航交付。
- **规范迭代与深度解析追加**：
  `docs: 补齐全量阶段架构总览与专题导航指引 (README.md)`  
  `docs: 完善大厂面试高频核心考题并沉淀通用教程工程化规范`  
  `refactor: 剔除所有生活化比喻，全面重塑为严谨的企业级工程架构心智`
