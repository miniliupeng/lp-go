# 专题 01：数据类型全貌速查与变量声明四部曲

> Go 语言是**编译型强类型静态语言**。每个变量都必须拥有确定类型，且**严格禁止隐式类型转换**。本专题带你一次性掌握 Go 的全部基本数据类型、内存大小、变量声明的 4 种姿势、零值体系，以及常量与 `iota` 自动枚举。

---

## 1. 基本数据类型全景速查清单

| 类型类别 | 具体类型 | 占用内存 | 取值范围 / 典型表现 | 零值（默认值） | 工业界最佳实践选型 |
| :--- | :--- | :---: | :--- | :---: | :--- |
| **布尔型** | `bool` | 1 字节 | `true` 或 `false` | `false` | 状态判断、开关标志 |
| **有符号整数** | `int8` | 1 字节 | $-128 \sim 127$ | `0` | 极小范围内存优化 |
| | `int16` | 2 字节 | $-32,768 \sim 32,767$ | `0` | 音频采样、硬件通讯 |
| | `int32` | 4 字节 | 约 $-21$ 亿 $\sim 21$ 亿 | `0` | 中等数值范围计算 |
| | `int64` | 8 字节 | 约 $-9\times 10^{18} \sim 9\times 10^{18}$ | `0` | **大厂标配**：时间戳（毫秒/纳秒）、数据库自增 ID |
| | **`int`** | 4/8 字节 | 64 位机器等价于 8 字节 | `0` | **默认首选**：日常计数、循环变量、切片下标 |
| **无符号整数** | `uint8` | 1 字节 | $0 \sim 255$ | `0` | 二进制原始字节流、RGB 颜色值 |
| | `uint16` | 2 字节 | $0 \sim 65,535$ | `0` | 端口号（Port）定义 |
| | `uint32` / `uint64` | 4/8 字节 | 纯正整数 | `0` | 绝不出现负数的超大数值计数 |
| | `uint` / `uintptr` | 4/8 字节 | 对应平台机器字长 / 存储内存地址数值 | `0` | 底层指针偏移（日常业务罕用） |
| **字符别名** | **`byte`** | 1 字节 | 等价于 `uint8`（单引号 `'a'`） | `0` | 表示一个 ASCII 字符或原始字节 |
| | **`rune`** | 4 字节 | 等价于 `int32`（单引号 `'中'`） | `0` | **表示一个 Unicode 字符**（支持中文、Emoji） |
| **浮点型** | `float32` | 4 字节 | 单精度浮点（有效位约 7 位） | `0.0` | 图像图形学低精度计算 |
| | **`float64`** | 8 字节 | 双精度浮点（有效位约 15~17 位） | `0.0` | **默认首选**：日常小数计算（财务金额推荐用整型分） |
| **复数型** | `complex128` | 16 字节 | 实部 float64 + 虚部 float64 | `(0+0i)` | 科学计算、傅里叶变换 |
| **字符串** | **`string`** | 16 字节 | 内部为指针+长度双字结构 | `""` | 文本传输（**Go 中 string 不可变**） |

> [!IMPORTANT]
> **绝对禁止隐式转换**：哪怕 `int` 和 `int64` 在 64 位机器底层占用完全一致的 8 字节，它们也是完全不同的类型，互相赋值或运算必须显式强转：`b = int64(a)`。

### 1.1 字符串的双重形态：双引号 vs 反引号

Go 提供了两种定义字符串字面量的方式：

| 语法形态 | 标识符 | 换行支持 | 转义字符行为 (`\n`, `\t`, `\"`) | 典型应用场景 |
| :--- | :---: | :---: | :--- | :--- |
| **标准解释型字符串** | `"..."` | 仅限单行 | **正常解析转义**（如 `\n` 输出真实换行） | 日常文本输出、短文本、日志消息 |
| **原生字符串字面量** | `` `...` `` | **原生支持多行** | **原样字面保留**（不转义任何字符，无视转义符） | 复杂多行 SQL、内嵌 JSON/HTML 模板、正则表达式 |

```go
// 双引号（遇到 \n 会被解析为换行）
query1 := "SELECT id, name FROM users\nWHERE status = 1"

// 原生反引号（所见即所得，保留真实排版与双引号）
query2 := `SELECT id, name
FROM users
WHERE status = "active" AND age > 18;`
```

## 2. 变量声明的 4 种正确姿势

```go
package main

import "fmt"

func main() {
    // 姿势 1：完整声明（var 变量名 类型 = 值）
    var age int = 18

    // 姿势 2：类型推导声明（省去类型，编译器自动推断）
    var name = "Gopher"

    // 姿势 3：短变量声明（最常用！:= 自动创建并赋值，仅限函数内使用）
    score := 98.5
    isGraduated := true

    // 姿势 4：批量声明（常用于全局变量或成组参数）
    var (
        city    string = "北京"
        zipCode int    = 100000
    )

    fmt.Println(name, age, score, isGraduated, city, zipCode)
}
```

### 2.1 ⚠️ 初学者必背铁律：局部变量“声明即必须使用”

Go 编译器对代码整洁度有着近乎偏执的要求：
* **局部变量铁律**：在函数体内部声明的任何局部变量，**必须在后续代码中被读取或使用**。如果声明了某个局部变量却从未调用，编译会立刻失败，报出经典错误：
  ```text
  ./main.go:10:5: declared and not used: unusedVar
  ```
* **包级全局变量例外**：在函数体外部声明的全局变量（Package-level var）允许暂时未被使用，编译器不会报错。
* **临时调试避坑技巧（空白标识符 `_`）**：开发过程中如果声明了变量暂时不用，可使用下划线静默丢弃：
  ```go
  tempDebugVar := calculateSomething()
  _ = tempDebugVar // 显式引用一次，临时骗过编译器检查
  ```

## 3. 常量（`const`）与 `iota` 自动枚举机制

在 Go 中，常量在编译期就已确定，无法修改。使用 `iota` 可以极其优雅地实现自增枚举：

```go
const (
    StatusPending = iota // 0 (首行 iota 从 0 开始)
    StatusRunning        // 1 (每换一行自动递增 1)
    StatusSuccess        // 2
    StatusFailed         // 3
)

// 使用 iota 结合位移定义文件容量单位
const (
    _  = iota             // 忽略第 0 项
    KB = 1 << (10 * iota) // 1 << 10 = 1024 Bytes
    MB = 1 << (10 * iota) // 1 << 20 = 1048576 Bytes (1MB)
    GB = 1 << (10 * iota) // 1 << 30 (1GB)
)
```
