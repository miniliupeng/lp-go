# 专题 02：运算符全景与独有位清空 (`&^`) 操作符

> Go 语言的运算符设计极其追求简洁与安全。它摒弃了 C/C++ 中容易引发歧义和未定义行为的隐式转换与复杂的运算符重载，并引入了独有的**位清空（AND NOT，`&^`）**运算符。

---

## 1. 基础运算符分类速查

### ① 算术运算符
- `+` (加)、`-` (减)、`*` (乘)、`/` (除，整数相除截断小数)、`%` (取模/求余数)
- **新手避坑（自增自减铁律）**：
  - Go 语言**只有 `i++` 和 `i--`**，**严禁写前置自增 `++i` 或 `--i`**！
  - 自增自减在 Go 中**是独立的语句（Statement），不是表达式（Expression）**！因此严禁写出 `a = i++` 或 `if i++ > 1` 这样的代码（编译器直接报错）。

### ② 关系运算符
- `==` (等于)、`!=` (不等于)、`>` (大于)、`<` (小于)、`>=` (大于等于)、`<=` (小于等于)
- 结果始终为 `bool`（`true` 或 `false`）。
- **要求**：参与比较的两个变量类型必须严格一致，类型不同连编译都无法通过。

### ③ 逻辑运算符
- `&&` (逻辑与，具备短路特性：前为 false 则后不计算)
- `||` (逻辑或，具备短路特性：前为 true 则后不计算)
- `!` (逻辑非，取反)

### ④ 常见位运算符
- `&` (按位与)：两位均为 1 时才为 1
- `|` (按位或)：有一位为 1 即为 1
- `^` (按位异或 / 兼有一元按位取反)：两位不同为 1，相同为 0
- `<<` (左移位)：`x << n` 相当于 $x \times 2^n$
- `>>` (右移位)：`x >> n` 相当于 $x / 2^n$

---

## 2. Go 独有运算符：位清空（`&^`，AND NOT）

Go 专门设计了 `&^` 运算符，其计算规则如下：
- **公式**：`z = x &^ y`
- **规则**：
  - 若 `y` 的某一位是 **1**，则强制将 `z` 的该位置为 **0**（清零）；
  - 若 `y` 的某一位是 **0**，则保持 `x` 的该位原值不变。

### 工业级应用场景：权限管理系统（RBAC 权限掩码剔除）
```go
const (
    PermRead    = 1 << 0 // 0001 = 1
    PermWrite   = 1 << 1 // 0010 = 2
    PermExecute = 1 << 2 // 0100 = 4
)

userPerm := PermRead | PermWrite // 0011 (具有读和写权限)

// 极其优雅地剔除写权限（无需繁琐的取反加与运算）
userPerm = userPerm &^ PermWrite // 0011 &^ 0010 = 0001 (仅剩读权限)
```
