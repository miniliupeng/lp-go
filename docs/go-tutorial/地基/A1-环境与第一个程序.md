# A1 环境与第一个程序

本章假设你能打开终端。示例在模块 `tutorial` 里运行，`go.mod` 写的是 **Go 1.27.1**。

## 安装

从 [https://go.dev/dl/](https://go.dev/dl/) 安装官方发行版。Linux 上常见做法是把压缩包解到 `/usr/local/go`，把 `/usr/local/go/bin` 加进 `PATH`。然后：

```bash
go version
go env GOROOT GOPATH GOPROXY GOTOOLCHAIN
```

`GOROOT` 是工具链目录。`GOPATH` 现在主要放模块缓存和默认的 `bin`。从 Go 1.16 起，在含有 `go.mod` 的目录里默认就是模块模式，新代码不要再放到 `GOPATH/src`。

`GOPROXY` 的默认值是 `https://proxy.golang.org,direct`。连不上官方代理时，可以在用户配置里改成别的代理，例如：

```bash
go env -w GOPROXY=https://goproxy.cn,direct
```

`go env -w` 写的是这台机器的用户配置，不要写进仓库。

在本仓库根目录执行命令时，`GOTOOLCHAIN=auto` 会按 `go.mod` 使用 Go 1.27.1，哪怕系统里的 `go` 命令更旧。格式化用 `go fmt`。系统里更旧的 `gofmt` 不认识 Go 1.27 的泛型方法。

## 第一个程序

[examples/a1hello/main.go](../../../examples/a1hello/main.go)：

```go
package main

import "fmt"

func main() {
    fmt.Println("你好，Go")
}
```

```bash
go run ./examples/a1hello
```

输出：

```text
你好，Go
```

`package main` 且有 `func main()` 的包才能当程序入口。`go build -o hello ./examples/a1hello` 会在当前目录生成二进制文件。

编辑器装 `gopls`，保存时格式化。`gofmt` 没有风格选项。

## 练习

把打印的字符串改成你的名字，再 `go run` 一次。在仓库根目录执行 `go env GOVERSION`，确认看到 `go1.27.1`。
