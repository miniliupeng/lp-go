# A2 声明、常量与运算符

main 的基础阶段把声明和运算符分成两讲。这一章把会写错的规则放在一起，每条都有测试。测试在 [examples/a2syntax](../../../examples/a2syntax/ops_test.go)。

## 这一章你要会什么

会声明变量和常量，说清零值，会算 `iota`、整数除法、`&^` 和短路。

## 声明

`var n int` 不赋值也能读。短声明 `n := 1` 只能写在函数里，左边至少要有一个新变量。`n, err := f()` 在 `err` 已经存在、`n` 是新名字时合法。两个都是旧名字时，`:=` 不能用，改成 `=`。

包级只能用 `var` 和 `const`，不能用 `:=`。

`_` 是空白标识符。用它丢掉一个返回值。它不能当普通变量再读出来。

## 零值

声明了却不赋值，读到的是该类型的零值，不是未定义内存。

| 类型 | 零值 |
| --- | --- |
| 数值 | 0 |
| `string` | `""` |
| `bool` | false |
| 指针、切片、map、channel、接口、函数 | nil |

局部变量同样是零值。说「Go 的局部变量是垃圾值」是错的。

## 常量、无类型常量与 iota

常量在编译期确定。没有类型的常量（untyped）可以在需要具体类型时再落地，所以 `const x = 1` 可以赋给 `int`，也可以赋给 `float64`，只要值能表示。写出类型的常量 `const x int64 = 1` 就只能当 `int64` 用。

```go
const (
    Red = iota // 0
    Green      // 1
    Blue       // 2
)
```

`iota` 在每个 `const` 块从 0 开始，每过一行加 1。跳行、表达式都按这个计数，不是按「出现了几次 iota 这个单词」。空标识符可以占一个编号：`_ = iota`。

## 运算符

整数除法向零截断。`-1/2` 是 `0`，不是 `-1`。余数的符号跟被除数走，`-1%2` 是 `-1`。关系是 `(a/b)*b + a%b == a`。

位移的右操作数必须是无符号整数，或能转成无符号的无类型常量。移位位数不能为负。

`&^` 是按位清除，一个运算符，不是两个。`x &^ y` 把 `y` 里为 1 的位从 `x` 清掉。`0b1110 &^ 0b0110` 得到 `0b1000`。对整数，结果和 `x & (^y)` 相同。

`++` 和 `--` 是语句，不是表达式。不能写 `if n++ > 0`，也不能写 `a = b++`。

`&&` 和 `||` 短路。左边已经能决定结果时，右边的函数不会执行。`&` 和 `|` 不短路，两边都会算。

比较运算符得到 `bool`。字符串按字节序比较。切片、map、函数不能用 `==`，除非和 nil 比（切片和 map 可以和 nil 比，函数也可以和 nil 比）。

## 自动分号

Go 在换行时，如果这一行的最后一个记号是标识符、字面量、`break`、`continue`、`fallthrough`、`return`、`++`、`--`、`)`、`]` 或 `}`，就会插入分号。所以下面这样写不能编译：

```go
if n > 0 {
    return
}
else {
    return
}
```

`}` 后面被插入了分号，`else` 就接不上这个 `if`。`else` 必须和前一个 `}` 写在同一行。这不是格式化偏好，是语法。

## 对比陷阱

| 写法 | 实际结果 |
| --- | --- |
| 认为 `-1/2` 向负无穷取整 | 得到 `0` |
| 把 `++` 写进表达式 | 编译失败 |
| `false && 有副作用的函数()` | 右边不执行 |
| `}` 和 `else` 分成两行 | 自动分号导致语法错误 |
| 两个旧变量用 `:=` | 编译失败，左边没有新名字 |

## 面试延伸

问运算符时，把三条说完：整数除法向零截断；`&^` 是按位清除；`&&` / `||` 短路而 `&` / `|` 不短路。问零值时，把数值、布尔、字符串和引用类型分开说，并明确局部变量也是零值。问 `:=` 时，说明它要求至少一个新变量，包级不能用。

## 问答题

### 问：`var n int` 和 `n := 0` 差在哪？

`var` 可以出现在包级和函数里，不赋值就是零值。`:=` 只能在函数里，并且左边至少有一个新名字。两个都是旧名字时改用 `=`。包级写成 `n := 0` 会编译失败。

### 问：无类型常量和 `const x int = 1` 有什么差别？

无类型常量在用到的地方再落地，只要目标类型能表示这个值。写出类型之后就只能当那个类型用。`iota` 在每个 `const` 块从 0 开始，每过一行加 1，空标识符也能占一个编号。

### 问：为什么 `-1/2` 是 0？

整数除法向零截断。余数的符号跟被除数走，所以 `-1%2` 是 `-1`。三者满足 `(a/b)*b + a%b == a`。不要按向负无穷取整来口算。

### 问：`&^` 和先按位取反再按位与，是一回事吗？

对整数，`x &^ y` 和 `x & (^y)` 的结果相同。`&^` 是一个运算符，名字叫按位清除：`y` 里为 1 的位从 `x` 清掉。测试里 `BitClear` 锁住了 `0b1110 &^ 0b0110 == 0b1000` 这一类结果。

### 问：短路会跳过函数调用吗？

`false && f()` 不会调用 `f`。`true || f()` 也不会。`&` 和 `|` 两边都算。用短路保护 nil 指针时，把判空放在左边。

### 问：`n++` 为什么不能写在 `if` 里？

`++` 和 `--` 是语句，不是产生值的表达式。要先 `n++`，再拿 `n` 做判断。

### 问：自动分号最容易踩在哪？

一行以 `}`、`)`、`]`、标识符、字面量、`return`、`break`、`continue`、`fallthrough`、`++` 或 `--` 结束时，换行会插入分号。所以 `else` 必须跟在 `}` 后面同一行。这是语法，不是 `gofmt` 的审美。

### 问：空白标识符可以再读出来吗？

不可以。`_` 用来丢掉返回值或占住 `iota`。它不是一个能读取的变量。
