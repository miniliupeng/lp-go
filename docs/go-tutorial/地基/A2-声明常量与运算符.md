# A2 声明、常量与运算符

## 声明和零值

`var n int` 不赋值也能读。数值是 0，`string` 是 `""`，`bool` 是 false，指针、切片、map、channel、接口和函数是 nil。局部变量不是未定义的内存。

`n := 1` 是短声明，只能在函数里用，至少要有一个新变量。包级变量用 `var` 或 `const`。

## 常量与 iota

```go
const (
    Red = iota // 0
    Green      // 1
    Blue       // 2
)
```

`iota` 在每个 `const` 块里从 0 开始，每行加 1。

## 运算符

整数除法向零截断：`-1/2` 是 `0`，余数的符号跟被除数走，`-1%2` 是 `-1`。`++` 和 `--` 是语句，不能写进表达式。

`&&` 和 `||` 会短路。左边已经能决定结果时，右边不会执行。

`&^` 是按位清除：`x &^ y` 把 `y` 里为 1 的位从 `x` 里清掉。`0b1110 &^ 0b0110` 得到 `0b1000`。

