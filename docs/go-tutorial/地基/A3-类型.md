# A3 类型

## 基本类型和转换

常用的有 `bool`、`int`、`int64`、`float64`、`string`、`byte`、`rune`。`byte` 是 `uint8` 的别名。`rune` 是 `int32` 的别名，表示一个 Unicode 码点。`int` 的宽度跟平台有关，协议字段写 `int32` 或 `int64`。

不同类型不能直接相加，要显式转换。`string(rune(65))` 是 `"A"`，因为 U+0041 是 A。`string(65)` 得到的也是这个码点，不是十进制文本 `"65"`。十进制文本用 `strconv.Itoa`。`go vet` 的 `stringintconv` 会提醒直接把整数转成字符串。

## 字符串

字符串是不可变的字节序列，通常按 UTF-8 解释。`len("中")` 是 3，`len([]rune("中"))` 是 1。下标 `s[i]` 是字节。逐个码点用 `for _, r := range s`。

## 数组和切片

数组长度是类型的一部分：`[3]int` 和 `[4]int` 不同。数组赋值会复制全部元素。

切片是一段描述：指向底层数组、长度、容量。`append` 在容量够的时候写进原来的底层数组，和它共享底层数组的切片能看见这次写入。容量不够时才分配新数组。测试 [TestAppendSharesBackingArray](../../../examples/a3types/types_test.go) 用 `make([]int, 3, 4)` 把这一点锁住：容量还剩 1，再 `append` 一个元素，短切片和原切片指向同一块内存。

扩容公式在 [C1](../运行时/C1-内存与逃逸.md)。它不是语言规范里的常数。

`make([]int, len, cap)` 创建切片。`new(T)` 分配 `T` 并返回 `*T`，内容是零值。切片、map、channel 用 `make`，因为它们还要有运行时里的内部结构。

## map 和指针

```go
v, ok := m["missing"] // 没有这个键时 v 是零值，ok 是 false
```

用 `ok` 区分「没有键」和「值就是零值」。map 的遍历顺序是随机的。两个 goroutine 同时写同一个 map 会 panic。

`p := &x` 取地址，`*p` 解引用。没有指针运算。对 nil 指针解引用会 panic。参数传递复制的是值；复制指针只复制地址，所以函数可以通过指针改到调用方的变量。

```bash
go test ./examples/a3types -count=1
```
