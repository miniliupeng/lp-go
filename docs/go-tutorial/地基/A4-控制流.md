# A4 控制流

Go 没有 `while`，也没有三元运算符。条件和循环都在 [examples/a4control](../../../examples/a4control/flow_test.go)。

## if 和 for

`if` 可以带一条短声明，作用域只在这个 `if` 和配套的 `else`：`if v, err := fn(); err != nil`。

三种循环都是 `for`：

```go
for i := 1; i <= n; i++ { }
for condition { }
for { } // 用 return 或 break 离开
```

`for i, v := range x` 遍历数组、切片、字符串、map 和 channel。遍历字符串时 `i` 是字节下标，`v` 是 `rune`。

**Go 1.22 起，每次迭代的循环变量都是新的。** `for i := range n` 里 `n` 是整数，`i` 从 0 取到 `n-1`。`RangeN(3)` 得到 `0, 1, 2`。

`break` 离开当前这一层 `for`、`switch` 或 `select`。`continue` 进入当前这一层 `for` 的下一次。`BreakOuter` 在内层用 `break outer` 离开外层，结果是 true。

## switch

命中一个 `case` 后就结束，不会掉进下一个。多个值写成 `case 2, 3:`。`Bucket(3)` 返回 `two-or-three`。

不写操作数时，每个 `case` 是一个条件，从上到下试到第一个为真的。`Command("sum")` 返回 `cmd=sum`。

`fallthrough` 只能作为当前 `case` 的最后一条语句，它跳到下一段语句，**不会**再计算下一个 `case` 的表达式。类型 switch 里不能写它。`Fall(3)` 返回 `fall=head-through`。

```bash
go test ./examples/a4control -count=1
```
