# A4 控制流

Go 只有 `if`、`for`、`switch`、`select` 和 `goto`。没有 `while`，也没有三元运算符。条件和循环都在 [examples/a4control](../../../examples/a4control/flow_test.go)。`select` 的就绪规则放在 [通道与选择](../运行时/C4-通道与选择.md)。

## 这一章你要会什么

写出带短声明的 `if`，用四种 `for` 遍历切片、字符串、map 和整数，用标签离开外层循环，并说清 `switch` 为什么默认不掉进下一个分支。

## if

`if` 可以带一条短声明，作用域只在这个 `if` 和配套的 `else`：

```go
if v, err := fn(); err != nil {
    return err
} else {
    use(v)
}
```

`v` 在 `if` 结束后不能再用。需要在后面继续用时，把声明写到 `if` 前面。

`else` 必须和前一个 `}` 写在同一行。换行时，编译器会在 `}` 后面插入分号，`else` 就接不上这个 `if`。完整的自动分号规则在 [声明、常量与运算符](A2-声明常量与运算符.md)。

## 四种 for

```go
for i := 1; i <= n; i++ { } // 三段式。SumTo 用的是这种
for condition { }           // 先判断再进循环体
for { }                     // 用 return 或 break 离开
for i, v := range x { }     // 遍历
```

`range` 的左值含义随右边的类型变：

| 右边 | 第一个变量 | 第二个变量 |
| --- | --- | --- |
| 数组、切片 | 下标 | 元素的副本 |
| 字符串 | 字节下标 | `rune` |
| map | 键 | 值的副本 |
| channel | 收到的值 | 没有第二个变量 |
| 整数（Go 1.22 起） | 从 0 到 `n-1` | 没有第二个变量 |
| `iter.Seq`（Go 1.23 起） | `yield` 交出来的值 | 见 [泛型与迭代器](../能写服务/B5-泛型与迭代器.md) |

`RangeN(3)` 得到 `0, 1, 2`。`for i := range n` 里 `n` 是整数。对字符串，一个码点可能占多个字节，下标会跳着走，见 [类型](A3-类型.md)。对 map，顺序每次运行可以不同。对 channel，循环一直收到关闭并取空为止；向一个没人关的 channel 做 `range` 会一直堵着。

遍历切片时，第二个变量是元素的副本。改这个副本不会改到底层数组。要改元素，用下标写回 `s[i] = ...`。

## 循环变量

**Go 1.22 起，每次迭代的循环变量都是新的。** 在循环里写 `go func() { use(i) }()`，闭包看到的是这一次迭代的 `i`。Go 1.21 及更早，`i` 是同一个变量，循环结束后所有闭包都看到最后一次的值。读旧代码时先看 `go.mod` 的版本。本仓库是 1.27.1，按每次迭代一个新变量来写。`SumSquares` 依赖这一点，见 [并发入门](../能写服务/B1-并发入门.md)。

## break、continue、标签

`break` 离开当前这一层 `for`、`switch` 或 `select`。`continue` 进入当前这一层 `for` 的下一次。在 `switch` 里面 `break`，离开的是 `switch`，外层循环还在继续。

要离开外层循环，给外层写标签：

```go
outer:
for {
    for {
        break outer
    }
}
```

`BreakOuter` 用的就是这个形式，结果是 true。标签只能放在语句前面，`break` 和 `continue` 的标签必须标在循环或 `switch` / `select` 上。`goto` 能跳到函数内的标签，跳不过变量声明。新代码优先用循环和函数返回，把 `goto` 留给从多层错误清理里跳到同一段收尾。

## switch

三种写法：

1. 带值。`switch n` 用 `==` 比较。命中一个 `case` 后就结束，不会掉进下一个。多个值写成 `case 2, 3:`。`Bucket(3)` 返回 `two-or-three`。
2. 不写值。每个 `case` 是一个条件，从上到下试到第一个为真的。`Command("sum")` 返回 `cmd=sum`。
3. 类型 switch。`switch v := x.(type)` 按动态类型分支。断言失败不会 panic，没匹配上就走 `default`。接口的细节在 [接口](A6-接口.md)。

`fallthrough` 只能作为当前 `case` 的最后一条语句。它跳到下一段语句，**不再计算下一个 `case` 的表达式**。类型 switch 里不能写它。`Fall(3)` 返回 `fall=head-through`：命中的是 3 那个分支，然后直接执行下一个分支的语句。

## 对比陷阱

| 写法 | 实际结果 |
| --- | --- |
| `}` 和 `else` 分成两行 | 自动分号，编译失败 |
| 以为 `switch` 会像 C 一样掉下去 | 默认结束。要下一段语句必须写 `fallthrough` |
| `fallthrough` 会再判断下一个条件 | 直接执行下一段，条件不再算 |
| 在 `switch` 里 `break` 想结束外层 `for` | 只离开 `switch`。离开外层用标签 |
| 改 `range` 得到的元素副本 | 底层数组不变。用下标写回 |
| 按 Go 1.21 的经验闭包捕获循环变量 | 1.22 起每次迭代是新变量 |

1. 把 `Command` 的输入改成 `"other"`，先写出返回值再跑测试。
2. 写一个两层循环，内层在 `i+j > 3` 时 `break` 到外层标签，数一下外层实际执行了几次。

## 面试延伸

问控制流时按这个顺序说：只有 `for`；`else` 不能单独换行；`switch` 默认不贯穿；`fallthrough` 不重新求值；Go 1.22 起循环变量每次迭代一份，`for i := range n` 从 0 走到 `n-1`。问「怎么跳出多层循环」时，给标签，并说明 `switch` 里的 `break` 不会结束外层 `for`。

## 问答题

### 问：`if` 的短声明能活到 `if` 外面吗？

不能。`if v, err := fn(); err != nil` 里的 `v` 和 `err` 只在这个 `if` 和配套的 `else` 里。后面还要用，就把声明写在 `if` 前面。

### 问：四种 `for` 各对应什么？

三段式、单条件、无限循环、`range`。没有 `while`。`SumTo` 用三段式，`RangeN` 用整数 `range`。无限循环必须有 `break` 或 `return`。

### 问：`range` 切片时改循环变量，元素会变吗？

第二个变量是元素的副本。要改底层数组，用下标写回 `s[i]`。`range` 字符串时第一个变量是字节下标，第二个是 `rune`。`range` map 的顺序不能依赖。`range` channel 直到关闭并取空。

### 问：Go 1.21 的循环变量坑，在本仓库还在吗？

不在。`go 1.27.1` 下每次迭代是新变量，闭包看到的是当次的值。读旧模块时先看 `go` 行。`loopclosure` 这个 vet 检查按文件的语言版本判断。

### 问：`break` 写在 `switch` 里，外层循环停吗？

不停。`break` 离开最内层的 `for`、`switch` 或 `select`。离开外层要给外层写标签，`BreakOuter` 就是这样做的，结果是 true。

### 问：`fallthrough` 会再算下一个条件吗？

不会。它直接执行下一段语句，而且只能放在当前 case 的最后。类型 switch 里不能写。`Fall(3)` 返回 `fall=head-through`。

### 问：不带操作数的 `switch` 和带值的 `switch` 怎么选？

带值时用 `==` 比较，多个值写成 `case 2, 3:`，`Bucket(3)` 得到 `two-or-three`。不带值时每个 case 是一个布尔表达式，从上到下试，`Command("sum")` 得到 `cmd=sum`。

### 问：`goto` 什么时候还能用？

可以跳到函数里的标签，不能跳过变量声明。新代码优先用循环、函数返回和带标签的 `break`。多层清理跳到同一段收尾时，`goto` 比重复五遍清理更清楚。
