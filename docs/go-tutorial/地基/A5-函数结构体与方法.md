# A5 函数、结构体与方法

示例在 [examples/a5struct](../../../examples/a5struct/task.go)。

## 函数

失败用额外的返回值表示，习惯上最后一个是 `error`。`Div(7, 2)` 得到商 3、余数 1、错误 nil。除数是 0 时返回 `divide by zero`，不 panic。

`Sum(nums ...int)` 在函数内部就是 `[]int`。已有切片时用 `sum(s...)`。

闭包捕获的是变量本身。`Counter()` 每次调用加 1，连续两次得到 1 和 2。

`defer` 把调用推迟到当前函数返回前，多个 `defer` 后进先出。`DeferOrder` 使用命名返回值，defer 里对它的修改调用方能看见，所以结果是 `body`、`defer 2`、`defer 1`。如果返回的是一个普通局部切片，defer 在 `return` 复制切片头之后才 append，调用方就看不见后面的元素。defer 语句的参数在执行到这一行时求值，不是等到函数返回时再求值。

## 结构体和方法

`Task` 嵌入 `Author`，所以 `By` 被提升，`item.By` 和 `item.Author.By` 是同一个字段。值接收者 `Label` 不修改原值。指针接收者 `Finish` 把 `Done` 设为 true。

可寻址的值会自动取地址，所以 `item.Finish()` 能调用指针方法。放进接口之后，这条自动取地址不再发生，见 [A6](A6-接口.md) 和 [C6](../运行时/C6-接口反射与剖析.md)。

Go 1.27 允许结构体字面量用提升字段的名字当键：`Task{By: "bea", Title: "note"}`。键必须是一个名字。`Author.By` 这种选择器不能当字面量键，编译器会报 `invalid field name`。

```bash
go test ./examples/a5struct -count=1
```

## 练习

给 `Task` 加一个值接收者 `IsOpen() bool`，`Done` 为 false 时返回 true，并补一个测试。
