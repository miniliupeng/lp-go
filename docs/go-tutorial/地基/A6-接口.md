# A6 接口

接口是一组方法。类型实现了这些方法，就实现了接口，不用写 `implements`。示例在 [examples/a6iface](../../../examples/a6iface/speak.go)。

`Dog` 有值接收者 `Speak`，所以 `Dog` 和 `*Dog` 都能放进 `Speaker`。`Announce(Dog{Name: "ada"})` 得到 `ada says woof`。从接口里取回具体类型用类型断言：`s.(Dog)`。断言失败时，带 `ok` 的形式返回 false，不 panic。

`*locked` 才有 `Read`。值 `locked` 的方法集里没有这个方法，不能赋给 `io.Reader`。可寻址的局部变量 `n.Read` 会自动取地址；放进接口之后，接口里保存的是值的副本，不会再自动取地址。所以指针方法要先取地址再放进接口。

接口值有两部分：动态类型和动态值。下面这个 `r` 不是 nil 接口，它的动态类型是 `*locked`，动态值是 nil：

```go
var p *locked
var r io.Reader = p
```

`r == nil` 为 false。对它 `Read` 会进到指针接收者，示例返回错误 `nil reader`。把「可能是 nil 的指针」直接放进 `error` 或 `io.Reader`，调用方的 `err == nil` 判断会失效。函数要返回失败时，返回一个没有动态类型的 nil 错误，或者返回非 nil 的具体错误。

```bash
go test ./examples/a6iface -count=1
```

## 练习

给 `Dog` 再写一个 `Cat`，用同一个 `Announce` 打印猫的叫声。不要改 `Announce` 的参数类型。
