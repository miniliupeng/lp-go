# A7 错误

`error` 是一个接口：`Error() string`。普通失败返回 `error`，不要 `panic`。`panic` 留给程序无法继续的故障，例如空指针解引用；库函数用返回值把问题交给调用方。示例在 [examples/a7err](../../../examples/a7err/check.go)。

`ErrEmpty` 是哨兵错误。`ParseAge("")` 返回它，调用方用 `errors.Is` 判断。`Is` 会沿着 `Unwrap` 往下找。

`ParseAge("4a")` 返回 `*FieldError`。`errors.As` 把这条链里第一个能放进目标类型的错误取出来。目标必须是指针，这里是 `**FieldError` 的地址，也就是 `&fe`，`fe` 的类型是 `*FieldError`。

`fmt.Errorf("...: %w", err)` 包装下一层错误，`Is` 和 `As` 仍然找得到。Go 1.27 的 printf 分析器会报告一种写错的包装：`%w` 的参数是 `*E`，而 `E` 自己实现了 `error`。诊断文本写的是这会破坏 `errors.Is`。包装时传 `E` 的值，或者让指针类型不要和值类型同时充当同一种错误。

`errors.Join` 把多个错误收成一个。`Together(ErrEmpty, ...)` 之后 `errors.Is` 仍能找到 `ErrEmpty`。某一个是 nil 时 `Join` 会丢掉它；全是 nil 时结果是 nil。

```bash
go test ./examples/a7err -count=1
```

## 练习

让 `ParseAge` 在数字大于 150 时返回 `*FieldError`，字段名仍是 `age`。用 `errors.As` 写测试。
