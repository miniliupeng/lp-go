# A8 包与模块

一个目录一个包。包名通常等于目录名。其他包只能使用大写开头的名字。`mathx.Add` 和 `mathx.Clamp` 在 [examples/a8calc/mathx](../../../examples/a8calc/mathx/mathx.go)。

导入路径是「模块路径 + 目录」。本仓库的 `go.mod` 是：

```text
module tutorial

go 1.27.1
```

所以 main 写成：

```go
import "tutorial/examples/a8calc/mathx"
```

`go` 那一行是这个模块声明的语言版本。`go vet` 的 `stdversion` 从 Go 1.22 起会按这一行（或文件顶部的 `//go:build go1.X`）拒绝「对这个文件来说太新」的标准库符号。

```bash
go test ./examples/a8calc/mathx
go run ./examples/a8calc
```

`go run` 的输出：

```text
add=8
clamp=5 err=<nil>
bad=mathx: lo 3 > hi 1
```

`Clamp(10, 0, 5)` 收到上限 5。`lo > hi` 时返回错误，不夹紧。

导入路径里出现元素 `internal` 时，只有它的父目录这棵树能导入它。这是编译器执行的规则。

初始化顺序：一个包先初始化它导入的包，每个包只初始化一次。包自己先按依赖给包级变量赋初值，再调用 `init`。多个文件时，构建系统按文件名字典序交给编译器。如果包 `p` 导入包 `q`，`q` 的 `init` 完成 happens before `p` 的初始化开始。`import _ "image/png"` 只为了执行对方的 `init`，让 `image.Decode` 认识 PNG。不要在 `init` 里启动停不下来的 goroutine，也不要在里面连数据库。

本教程的示例只用标准库，没有第三方 `require`。以后加了依赖，把 `go.sum` 和 `go.mod` 一起提交。
