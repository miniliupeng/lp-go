# A9 标准库与测试

## 测试

测试文件以 `_test.go` 结尾，函数名是 `TestXxx(t *testing.T)`。`go test` 不会把它们编进普通二进制文件。

[lines_test.go](../../../examples/a9text/lines_test.go) 把输入和期望放进切片，用 `t.Run` 分子测试。`t.Fatal` 结束当前测试函数，`t.Errorf` 记录失败并继续。辅助函数第一行写 `t.Helper()`，报错行号会指向调用处。

`slices.Equal` 把 nil 和空切片看成相等。`NonEmptyLines("")` 返回 nil。如果必须区分 nil 和空切片，不要用它。`"a\r\n b"` 的结果是 `a` 和 `b`：`TrimSpace` 会去掉 `\r`。

`ExampleNonEmptyLines` 的输出要和 `// Output:` 注释逐字相同。

Go 1.22 起每次循环迭代有自己的变量，子测试里再 `t.Parallel()` 时看到的是当次的用例。并行的子测试不要写同一个没有同步的变量。

`t.Cleanup` 在该测试和它的子测试都结束后执行，后注册的先执行。Go 1.24 起 `t.Context()` 返回的 context 会在这些 Cleanup 函数被调用之前取消。

```bash
go test ./examples/a9text -cover
```

`-cover` 统计的是语句有没有执行到，不是分支覆盖。

## flag、JSON、路径、时间

[examples/a9stdlib/main.go](../../../examples/a9stdlib/main.go)：

```bash
go run ./examples/a9stdlib -name Ada -upper
```

```text
name=Ada
- LEARN GO (done)
- WRITE TOOL (todo)
base=readme.md
when=2026-01-02T15:04:05Z
```

`flag.String` 返回指针，`Parse` 之后用 `*name`。旗标要出现在普通参数前面。

JSON 字段必须大写，编码包才能看见。`json:"title"` 决定对象里的名字。这段 JSON 是源码里的常量，`Unmarshal` 失败就 `panic`。解析用户输入时要返回 `error`，见 [A7](A7-错误.md)。重复键的差别在 [B4](../能写服务/B4-JSON与文件.md)。

`path/filepath` 处理本机路径，`path` 处理 URL 路径。`filepath.Base(filepath.Join("docs", "readme.md"))` 得到 `readme.md`。

`time.Format` 的布局参照的是 2006-01-02 15:04:05。`time.RFC3339` 就是这个布局。示例的时刻在 UTC，所以结果以 `Z` 结尾。

读小文件用 `os.ReadFile`。按行读用 `bufio.Scanner`，默认单行上限 64 KiB，超长时 `Scan` 失败，用 `sc.Err()` 取原因。打开文件先判断错误，成功后再 `defer f.Close()`。
