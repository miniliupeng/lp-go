# B5 泛型与迭代器

示例在 [examples/b5gen](../../../examples/b5gen/set.go)。

## 类型参数

`Set[T comparable]` 的元素必须能用 `==` 比较，所以约束是 `comparable`。切片、map 和函数不能当 `comparable` 的类型实参。

`MapSlice[S ~[]E, E any, R any]` 里的 `~[]E` 表示底层类型是 `[]E` 的类型，包括你自己 `type Ints []int`。函数体里按 `[]E` 来用。

能用接口或 `any` 写清楚时，不必上类型参数。泛型适合容器和算法，不适合为了少写一个接口。

## 泛型方法

Go 1.27 可以写 `func (Box) Identity[T any](v T) T`。接口方法不能带类型参数，泛型方法也不能用来实现接口方法。需要「对很多类型做同一件事」并且要放进接口时，继续用接口，或者用类型参数写函数而不是方法。

## 提升字段

`outer{X: 7}` 在 Go 1.27 里合法，`X` 是嵌入的 `inner` 提升上来的字段名。这和泛型无关，放在同一组测试里，是为了把「1.27 才编译得过」的写法收在一处。

## 迭代器

Go 1.23 起 `for range` 可以遍历 `iter.Seq[V]`，它的类型是 `func(yield func(V) bool)`。`yield` 返回 false 时必须停，并且不能再调用 `yield`，否则 panic。`break` 会让 `yield` 返回 false。`CountDown(5)` 在 3 处 break，得到 `5, 4, 3`。

`maps.Keys`、`slices.Values` 返回的就是这种迭代器。

```bash
go test ./examples/b5gen -count=1
```

## 练习

给 `Set` 加 `Len() int`。用 `comparable` 能通过的类型写一个测试，再用一个不能比较的类型确认它编译失败（这个失败不要留在仓库里）。
