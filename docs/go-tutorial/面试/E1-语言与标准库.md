# E1 语言与标准库

先合上正文再答。每题答到下面的采分点。采分点只来自本教程写过、并且能在 Go 1.27.1 的示例或源码注释里对上的内容。

### 1. `var s string` 不赋值，读出来是什么？

采分点：`""`。数值是 0，`bool` 是 false，指针、切片、map、channel、接口、函数是 nil。见 [声明、常量与运算符](../地基/A2-声明常量与运算符.md)。

### 2. `len("中")` 和 `[]rune("中")` 的长度？

采分点：字节是 3，码点是 1。下标取到的是字节。见 [类型](../地基/A3-类型.md)。

### 3. `0b1110 &^ 0b0110` 等于多少？`-1/2` 呢？

采分点：按位清除得到 `0b1000`。整数除法向零截断，`-1/2` 是 0，`-1%2` 是 -1。`++` 是语句。`&&` 和 `||` 短路。

### 4. 容量还够时 `append` 会影响别的切片吗？

采分点：会写进同一块底层数组。容量不够才换新数组。扩容倍数不是语言常数，`nextslicecap` 还会再按大小类取整。见 [内存与逃逸](../运行时/C1-内存与逃逸.md)。

### 5. `for` 循环变量从哪一版开始每次迭代都是新的？

采分点：Go 1.22。`for i := range n` 里 `n` 是整数，`i` 从 0 到 `n-1`。`fallthrough` 不重新计算下一个 case。见 [控制流](../地基/A4-控制流.md)。

### 6. 为什么 `var p *T = nil` 放进 `error` 之后 `err == nil` 是 false？

采分点：接口值包含动态类型。类型是 `*T`、值是 nil，这不是 nil 接口。见 [接口](../地基/A6-接口.md)。

### 7. `errors.Is` 和 `errors.As` 各找什么？

采分点：`Is` 沿 `Unwrap` 找哨兵。`As` 把链上第一个能放进目标类型的错误写进去，目标是指针。`Join` 之后仍能 `Is` 到其中一项。见 [错误](../地基/A7-错误.md)。

### 8. `encoding/json` 和 `encoding/json/v2` 对重复键有什么差别？

采分点：v1 的 `Unmarshal` 后写覆盖前写。v2 的 `Unmarshal` 默认拒绝重复键。Go 1.27 的 v1 API 由 v2 实现承接，但这条可见行为还在。见 [JSON 与文件](../能写服务/B4-JSON与文件.md)。
