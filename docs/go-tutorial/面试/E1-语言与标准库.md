# E1 语言与标准库

先合上正文再答。每题给出可以开口说的回答，采分点都来自本教程写过、并且能在 Go 1.27.1 的示例或源码里对上的内容。不要报某台机器的 `ns/op`。

## 1. 零值

`var s string` 不赋值，读出来是 `""`。数值是 0，`bool` 是 false，指针、切片、map、channel、接口、函数是 nil。局部变量也是零值，不是未初始化的垃圾。见 [声明、常量与运算符](../地基/A2-声明常量与运算符.md)。

## 2. 字符串和码点

`len("中")` 是 3，`len([]rune("中"))` 是 1。字符串是字节序列，`len` 是字节数。`range` 一次交出一个码点，下标按字节跳。`string(65)` 是码点 U+0041，也就是 `"A"`，不是十进制文本 `"65"`。见 [类型](../地基/A3-类型.md)。

## 3. 运算符

`0b1110 &^ 0b0110` 是按位清除，得到 `0b1000`。整数除法向零截断，`-1/2` 是 0，`-1%2` 是 -1。`++` 是语句，不能写进表达式。`&&` 和 `||` 短路，`&` 和 `|` 不短路。`else` 必须和前一个 `}` 同一行，否则自动分号会把 `else` 断开。

## 4. 切片

切片是指针、长度、容量。赋值只复制这三个字段。容量还够时 `append` 写进同一块底层数组，其它共享它的切片看得见。容量不够才换新数组。三下标 `s[i:j:k]` 把容量限制成 `k-i`。`copy` 只复制两边长度的较小值。

扩容不是语言常数。`nextslicecap`：新长度大于旧容量两倍时用新长度；旧容量小于 256 时翻倍；否则按 `newcap += (newcap + 3*256) >> 2` 增长，再按大小类取整。见 [内存与逃逸](../运行时/C1-内存与逃逸.md)。

nil 切片可以 `append`。`encoding/json` 里 nil 切片编码成 `null`，空切片编码成 `[]`。`slices.Equal` 把两者看成相等。

## 5. map

用 `ok` 区分没有键和值本身是零值。向 nil map 写入会 panic，`delete` 一个不存在的键不会。并发写 panic。遍历顺序随机。Go 1.27.1 的实现在 `internal/runtime/maps`，注释写明基于 Swiss Table：8 个槽一组，控制字里放 H2。这是实现，语言层面仍是无序哈希表。

## 6. 控制和函数

Go 1.22 起每次迭代的循环变量是新的。`for i := range n` 从 0 到 `n-1`。`switch` 默认不贯穿。`fallthrough` 不重新计算下一个 case，类型 switch 里不能写。

参数永远是值的副本。`defer` 后进先出，参数在执行到 `defer` 那一行时求值。命名返回值让 defer 能改到调用方看见的结果。`recover` 必须在出 panic 的那个 goroutine 的 defer 里直接调用。方法集：`T` 只有值接收者，`*T` 两者都有。Go 1.27.1 的结构体字面量可以用提升字段的名字当键，不能用选择器。

## 7. 接口和错误

接口值有动态类型和动态值，两半都空才是 nil。`var p *T = nil` 放进 `error` 之后 `err == nil` 是 false。运行时：`any` 是 `eface`（类型加数据），带方法的接口是 `iface`（`itab` 加数据）。

`errors.Is` 沿 `Unwrap` 找哨兵。`errors.As` 把链上第一个能放进目标类型的错误写进去，目标是指针。`%w` 保留链条，`%v` 只留文本。`errors.Join` 丢掉 nil 项，全是 nil 时结果是 nil。Go 1.27 的 printf 分析会报告：`%w` 的参数是 `*E` 而 `E` 实现了 `error`，这会破坏 `errors.Is`。不要用 `Error()` 的句子做分支。

## 8. JSON、模块和测试

`encoding/json` 的 `Unmarshal` 对重复键后写覆盖：`{"a":1,"a":2}` 得到 2。`encoding/json/v2` 默认拒绝重复键。缺字段得到零值，不报错。用户路径用 `os.Root`，`filepath.Join` 挡不住 `..`。

`go.mod` 是要求清单，`go.sum` 是内容哈希。MVS 对每个模块取所有要求中的最高版本，也就是满足全部下限的最低版本。`replace` 只影响主模块自己的构建。`internal` 由编译器限制导入。

测试用表驱动和 `t.Run`。`t.Cleanup` 后进先出。Go 1.24 起 `t.Context()` 在 Cleanup 之前取消。`for b.Loop()` 把准备和清理排除在计时之外。比较时刻用 `time.Equal`。参考时间是 `2006-01-02 15:04:05`。

## 追问

### 问：`go.sum` 和 MVS 各管什么？

MVS 决定用哪个版本：每条 `require` 是下限，每个模块取要求中的最高版本。`go.sum` 记录那个版本的内容哈希，用来发现字节被换掉。`replace` 只在主模块自己的构建里生效。

### 问：`defer` 的参数什么时候求值？

执行到 `defer` 这一行就求值。`DeferArg` 得到 1，不是后来改成的 2。命名返回值让 defer 能改调用方看见的结果，`DeferOrder` 是 `body`、`defer 2`、`defer 1`。`recover` 必须在出 panic 的 goroutine 的 defer 里直接调用，`Recovered` 得到 `"boom"`。

### 问：nil 切片、空切片、JSON 三者怎么说？

长度都是 0。nil 和 nil 比较为真。`append(nil, x)` 合法。`slices.Equal` 把 nil 和空切片看成相等。`encoding/json` 把 nil 编成 `null`，把空切片编成 `[]`。

### 问：`omitempty` 会把 0 省掉吗？

会。空值包括 false、0、nil 指针，以及长度为零的数组、切片、map 和字符串。数量如果 0 有意义，不要加这个选项。

### 问：循环变量从哪一版开始每次迭代都是新的？

Go 1.22。同时有 `for i := range n`。`switch` 默认不贯穿，`fallthrough` 不重新求值。`else` 必须和 `}` 同一行。

### 问：泛型方法和接口？

Go 1.27 可以在具体类型上写带类型参数的方法。接口方法不能有类型参数，泛型方法也不能用来实现接口。`comparable` 排除切片、map 和函数。`~` 把底层类型算进来。迭代器从 Go 1.23 开始，`yield` 返回 false 必须停。
