# E2 运行时与并发

### 1. GMP 里 syscall 时 P 还在不在？

采分点：G 在 `_Gsyscall` 时占用 M，不拥有 P。`_Grunnable`、`_Grunning`、`_Gsyscall`、`_Gwaiting` 在 Go 1.27.1 源码里是 1、2、3、4。这是 iota，不是稳定 ABI。见 [调度器](../运行时/C2-调度器.md)。

### 2. 空转循环一定能证明异步抢占用的是 SIGURG 吗？

采分点：Unix 上 `sigPreempt` 是 `_SIGURG`，这是源码。示例里的忙循环调用了 `atomic.Bool.Load`，那是同步安全点，测试只说明 `GOMAXPROCS=1` 时另一个 goroutine 还能跑到。

### 3. 默认 GC 是分代的吗？写屏障涂什么？

采分点：默认收集器并发、精确、非分代、非整理。Green Tea 要 `GOEXPERIMENT=greenteagc`，默认 `GreenTeaGC` 为 false。写屏障总是涂被覆盖的旧指针；当前栈仍是灰色时再涂新指针。STW 在清扫终止和标记终止。见 [垃圾回收](../运行时/C3-垃圾回收.md)。

### 4. `SetMemoryLimit` 统计哪些内存？

采分点：软上限对应 `MemStats.Sys - MemStats.HeapReleased`，或两个 `runtime/metrics` 名字相减。不包括二进制、C 内存、运行时不管的 mmap。传入负数只读不改。

### 5. 关闭 channel 之后发送会怎样？nil channel 在 select 里呢？

采分点：向已关闭的 channel 发送会 panic。已取空再接收得到零值和 `ok == false`。nil channel 的 case 不会被选中。多个就绪 case 是伪随机。Go 1.27 上 `time.NewTimer` 的 `C` 容量是 0。见 [通道与选择](../运行时/C4-通道与选择.md)。

### 6. 取消 context 会杀掉 goroutine 吗？`Cause` 和 `Err` 有何差别？

采分点：不会。函数自己看 `ctx.Err()`。`WithCancelCause` 之后 `Err` 是 `Canceled`，`Cause` 是传入的原因。不要用 `select` 的 `default` 和 `Done` 抢。见 [上下文与日志](../能写服务/B2-上下文与日志.md)。

### 7. `sync.Map` 和 `sync.Pool` 能不能当通用缓存？

采分点：多数 map 用锁。`sync.Map` 适合写一次读很多次，或键按 goroutine 分开。`Pool` 里的对象可以被 GC 清掉。Mutex 饥饿阈值在实现里是 1 毫秒，不要背成语言规范。见 [同步与原子](../运行时/C5-同步与原子.md)。

### 8. `reflect.ValueOf(n).CanSet()` 为什么是 false？

采分点：这个值不可寻址。`ValueOf(&n).Elem()` 才可以 `Set`。未导出字段仍然不能 `Set`。见 [接口、反射与剖析](../运行时/C6-接口反射与剖析.md)。
