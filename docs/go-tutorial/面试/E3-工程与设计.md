# E3 工程与设计

### 1. `ReadTimeout` 为 0 表示什么？它包不包括 body？

采分点：0 或负数表示不设超时。`ReadTimeout` 包含 body。`ReadHeaderTimeout` 为 0 时回退到 `ReadTimeout`。见 [HTTP 超时与关闭](../工程/D1-HTTP超时与关闭.md)。

### 2. `Shutdown` 会不会打断正在跑的 Handler？

采分点：不会。它先关监听和空闲连接，再等活跃连接回到空闲。context 到期返回 context 的错误。`Serve` 在 `Shutdown` 被调用后返回 `ErrServerClosed`。Hijack 的连接不在等待范围内。

### 3. 教学驱动 `sqltut` 是隔离级别吗？

采分点：不是。同一键后提交覆盖先提交，不同键都保留。`database/sql` 在事务里调用的是连接上的 `Exec` / `Query`，连接必须记住事务。见 [数据库与事务](../工程/D2-数据库与事务.md)。

### 4. 击穿、穿透、雪崩，示例各解决了哪一个？

采分点：singleflight 合并同一次在途调用，不留结果。负缓存针对穿透，TTL 必须短。令牌桶的突发上限是 `burst`。单机桶不是全局限流。见 [缓存与限流](../工程/D3-缓存与限流.md)。

### 5. 半开状态为什么只放一个请求？

采分点：那是探测。失败就重新打开并重算冷却，成功才回到关闭。示例不把 4xx 单独分类。见 [熔断、重试与可观测性](../工程/D4-熔断重试与可观测性.md)。

### 6. 为什么延迟不看平均数？内存打点为什么不用 `ReadMemStats`？

采分点：平均数会被大量快请求拉低。`ReadMemStats` 会短暂 STW。软上限看 `/memory/classes/total:bytes` 减去 `/memory/classes/heap/released:bytes`。

### 7. 这份短链的短码为什么是 `"1"` 和 `"2"`？线上为什么不能这么做？

采分点：递增的 62 进制，第一次加 1 得到 `"1"`。递增码暴露顺序。62 进制 6 位是 56,800,235,584，仍然要处理冲突。过期时刻本身算过期。301 会被浏览器长期记住。见 [短链设计](../工程/D5-短链设计.md)。

### 8. `go vet` 的 `stdversion` 从哪一版开始看 `go.mod`？

采分点：Go 1.22 起。文件版本由 `go` 行或 `//go:build go1.X` 决定。Go 1.27 的 printf 分析会报告用 `%w` 包装 `*E`（`E` 实现了 `error`）会破坏 `errors.Is`。见 [目录与检查](../能写服务/B6-目录与检查.md)。
